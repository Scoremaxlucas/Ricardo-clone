# 🔥 Domain Warm-up Plan für helvenda.ch

## Warum Domain Warm-up?

**Neue Domains haben keine Reputation.** E-Mail-Provider (Gmail, Outlook, etc.) sind sehr vorsichtig bei neuen Domains. Wenn du zu schnell zu viele E-Mails sendest, landen sie im Spam.

**Lösung:** Langsam starten und Reputation aufbauen.

## 📅 Warm-up Zeitplan

### Woche 1: 10-20 E-Mails/Tag
**Ziel:** Domain bekannt machen, erste positive Signale senden

**Regeln:**
- ✅ **Nur** Transaktions-E-Mails (E-Mail-Verifizierung, Verkäufe, Käufe)
- ✅ **Nur** an registrierte User die sich aktiv angemeldet haben
- ✅ **Nur** an verifizierte E-Mail-Adressen
- ❌ **KEINE** Marketing-E-Mails
- ❌ **KEINE** Newsletter
- ❌ **KEINE** Bulk-E-Mails

**Monitoring:**
- Öffnungsrate sollte >15% sein
- Bounce Rate sollte <5% sein
- Spam Complaints sollten 0 sein

### Woche 2: 50-100 E-Mails/Tag
**Ziel:** Reputation langsam aufbauen

**Regeln:**
- Weiterhin nur Transaktions-E-Mails
- Nur an engagierte User (die sich registriert/angemeldet haben)
- Weiterhin keine Marketing-E-Mails

**Monitoring:**
- Öffnungsrate sollte >18% sein
- Bounce Rate sollte <4% sein
- Spam Complaints sollten 0 sein

### Woche 3-4: 200-500 E-Mails/Tag
**Ziel:** Reputation weiter aufbauen

**Regeln:**
- Weiterhin nur Transaktions-E-Mails
- Kann langsam mehr E-Mails senden
- Weiterhin keine Marketing-E-Mails

**Monitoring:**
- Öffnungsrate sollte >20% sein
- Bounce Rate sollte <3% sein
- Spam Complaints sollten <0.1% sein

### Nach 1 Monat: Normal
**Ziel:** Domain sollte jetzt Reputation haben

**Regeln:**
- Kann normale Volumen senden
- Kann langsam Marketing-E-Mails hinzufügen (wenn gewünscht)
- Weiterhin Transaktions-E-Mails priorisieren

**Monitoring:**
- Öffnungsrate sollte >20% sein
- Bounce Rate sollte <2% sein
- Spam Complaints sollten <0.1% sein

## 🎯 Best Practices während Warm-up

### ✅ DO:
1. **Nur Transaktions-E-Mails** - E-Mail-Verifizierung, Verkäufe, Käufe, etc.
2. **Nur an engagierte User** - User die sich registriert/angemeldet haben
3. **Engagement fördern** - User sollten E-Mails öffnen/klicken
4. **Bounce Management** - Hard Bounces sofort entfernen
5. **Spam Complaints überwachen** - Sofort reagieren wenn >0.1%

### ❌ DON'T:
1. **KEINE Marketing-E-Mails** - In den ersten 4 Wochen
2. **KEINE Newsletter** - In den ersten 4 Wochen
3. **KEINE Bulk-E-Mails** - In den ersten 4 Wochen
4. **KEINE nicht-verifizierte E-Mails** - Immer verifizieren
5. **KEINE zu schnellen Volumen-Sprünge** - Langsam steigern

## 📊 Monitoring Tools

### 1. Resend Dashboard
- Gehe zu: https://resend.com/emails
- Überwache:
  - **Delivery Rate:** Sollte >95% sein
  - **Bounce Rate:** Sollte <5% sein
  - **Spam Complaints:** Sollte <0.1% sein

### 2. Google Postmaster Tools
- Gehe zu: https://postmaster.google.com/
- Füge `helvenda.ch` hinzu
- Überwache:
  - **Domain Reputation:** Sollte "Good" sein
  - **IP Reputation:** Sollte "Good" sein
  - **Authentication Rate:** Sollte >95% sein

### 3. Microsoft SNDS
- Gehe zu: https://sendersupport.olc.protection.outlook.com/snds/
- Füge `helvenda.ch` hinzu
- Überwache Reputation

### 4. Mail-Tester.com
- Gehe zu: https://www.mail-tester.com/
- Teste regelmäßig (1x pro Woche)
- **Ziel:** Score 8-10/10

## 🚨 Red Flags (Sofort stoppen!)

Wenn eines dieser Probleme auftritt, **sofort stoppen** und analysieren:

1. **Bounce Rate >10%** - Zu viele ungültige E-Mails
2. **Spam Complaints >0.5%** - User markieren als Spam
3. **Öffnungsrate <10%** - User öffnen E-Mails nicht
4. **Domain auf Blacklist** - Domain wurde blockiert

## 💡 Quick Wins

1. **User markieren als "Not Spam"** - Bitte User darum, E-Mails als "Not Spam" zu markieren
2. **Engagement fördern** - User sollten E-Mails öffnen/klicken
3. **Nur Transaktions-E-Mails** - Keine Marketing in den ersten Wochen
4. **Bounce Management** - Hard Bounces sofort entfernen

## 📈 Erwartete Ergebnisse

### Nach 1 Woche:
- ✅ E-Mails landen noch teilweise im Spam (normal)
- ✅ Delivery Rate sollte >90% sein
- ✅ Bounce Rate sollte <5% sein

### Nach 2 Wochen:
- ✅ E-Mails landen weniger im Spam
- ✅ Delivery Rate sollte >93% sein
- ✅ Bounce Rate sollte <4% sein

### Nach 1 Monat:
- ✅ E-Mails sollten hauptsächlich im Posteingang landen
- ✅ Delivery Rate sollte >95% sein
- ✅ Bounce Rate sollte <3% sein
- ✅ Domain Reputation sollte "Good" sein

### Nach 2-3 Monaten:
- ✅ E-Mails sollten normal funktionieren
- ✅ Delivery Rate sollte >97% sein
- ✅ Bounce Rate sollte <2% sein
- ✅ Domain Reputation sollte "Good" sein

## 🆘 Wenn es nicht funktioniert

Nach 1 Monat Warm-up sollte es besser sein. Wenn nicht:

1. **Prüfe Mail-Tester.com Score** - sollte >8 sein
2. **Prüfe Domain Blacklist** - sollte OK sein
3. **Prüfe Google Postmaster** - Domain Reputation sollte "Good" sein
4. **Kontaktiere Resend Support:** support@resend.com
   - Erkläre das Problem
   - Bitte um Hilfe bei Deliverability
